# Security

This repository contains educational material, not the frameworks themselves.

- Vulnerabilities in `sovereign-agent` or `zeocore`: report on their product
  repositories.
- Problems with material here (a resource that leaks credentials, executes
  something it should not): open a private security advisory on this
  repository or contact the maintainers in MAINTAINERS.md.

No resource in this catalog requires real credentials to run its core path;
treat any resource that demands a secret for its basic demo as a bug.
